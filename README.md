# Happy Birthday, Sis!

A responsive birthday greeting page built with React, Vite, and Tailwind CSS. It uses a pink palette with lilac, mint, and butter-yellow accents, and includes a colorful “Learn” link that jumps to a sister appreciation section.

## Run locally

```bash
npm install
npm run dev
```

The reference folder `C:/Users/acer/Documents/Sissy_birthday/` was empty when inspected, so the greeting uses a warm, generic sister message that is easy to personalize in `src/App.jsx`.
